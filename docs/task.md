# Постановка сквозной задачи

Автоматизированная проверка публикаций кафедры по Единому
государственному перечню научных изданий (ЕГПНИ) с формированием
служебной записки.

## Входные данные

1. **Конфигурационный файл** `config/criteria.yaml` — параметры
   проверки. Источник: локальный акт вуза. Формат: YAML.
   Содержит версию ЕГПНИ, пороговый уровень, отчётный период и
   признак необходимости аффилиации.

2. **Список публикаций кафедры** — файл `data/raw/publications.csv`.
   Источник: выгрузка из учётной системы кафедры. Формат: CSV.
   Поля: id, title, authors, journal, year, level, issn, doi,
   affiliation.

3. **Справочник ЕГПНИ** — файл `data/reference/registry.csv`.
   Источник: выгрузка из ЕГПНИ. Формат: CSV.
   Поля: journal, issn, level, subject_area, quartile.

## Выходные данные

1. **Протокол проверки** — `data/output/report.csv`.
   Столбцы: id, решение, причина.

2. **Служебная записка** — `data/output/memo.md`.
   Содержит шапку, основание, таблицу засчитанных публикаций
   и итоговую сводку по количеству засчитанных, не засчитанных
   и отложенных на ручную проверку.

## Правила обработки

1. Название издания сверяется со справочником ЕГПНИ указанной
   версии. Уровень и квартиль берутся из справочника.
2. Публикация засчитывается, если её уровень не превышает
   значение `max_level` из конфигурационного файла.
3. Публикация засчитывается, если год попадает в диапазон
   `period.start_year … period.end_year` включительно.
4. Если `require_affiliation: true`, публикация засчитывается
   только при наличии аффилиации с вузом.
5. Все правила проверяются по порядку:
   издание → уровень → год → аффилиация.
   Первое невыполненное правило — причина отказа.

## Исключительные случаи

| Случай | Как обрабатывается |
|--------|--------------------|
| В записи не указаны ни DOI, ни ISSN | Публикация не засчитывается автоматически и включается в список для ручной проверки |
| Название издания записано иначе, чем в справочнике | Название нормализуется (регистр, пробелы, дефисы) и ищется в справочнике. Если найдено — уровень берётся оттуда. Если нет — запись уходит на ручную проверку |
| У издания несколько квартилей по разным предметным областям | Квартиль на зачёт не влияет. В служебную записку попадает квартиль по предметной области публикации |
| Издание не найдено в справочнике | Публикация не засчитывается. Причина: «издание отсутствует в ЕГПНИ» |
| Внешний источник недоступен | Программа использует только локальные файлы. Если файл справочника отсутствует или повреждён — завершается с ошибкой |
| Уровень издания не указан в справочнике | Публикация не засчитывается. Причина: «не указан уровень издания» |
| Год публикации вне отчётного периода | Публикация не засчитывается. Причина: «год вне отчётного периода» |
| Дубликат записи (совпадают ISSN и год) | Оставляется первая запись. В протоколе пометка «дубликат» |

## Требования в проверяемой форме

| № | Требование | Способ проверки |
|---|------------|-----------------|
| Т1 | Программа запускается командой `uv run python main.py`, читает конфиг, публикации и справочник, завершается кодом 0 | Запуск на эталонном наборе |
| Т2 | Публикация засчитывается, только если её уровень не превышает `max_level` | Тест: публикация с уровнем выше `max_level` → «не засчитана» |
| Т3 | Публикация засчитывается, только если год попадает в диапазон `period` включительно | Тест на границы: год = start_year, год = end_year, год вне диапазона |
| Т4 | При `require_affiliation: true` публикация без аффилиации не засчитывается, причина указывается | Тест: проверить причину в report.csv |
| Т5 | Программа создаёт `report.csv` и `memo.md`; сводка в memo.md совпадает с report.csv | Просмотр файлов после запуска |
